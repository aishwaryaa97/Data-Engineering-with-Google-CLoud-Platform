# Data Engineering with Google Cloud Platform

Hands-on learning and practice repository based on the book **Data Engineering with Google Cloud Platform**, published by Packt.

## About

This repository contains code and exercises explored while learning Google Cloud Platform and Data Engineering concepts.

The repository covers practical examples related to:

- Google Cloud Platform (GCP)
- BigQuery
- Cloud Storage
- Pub/Sub
- Dataflow
- Cloud Composer / Apache Airflow
- Dataproc
- Python
- Data Engineering workflows
